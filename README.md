# MG인재개발원 명찰·명패 출력 프로그램

인터넷 없이 동작하는 HTML 파일 1개짜리 프로그램입니다. 사내 인트라넷에서도 사용할 수 있습니다.

- **실행:** `index.html`을 내려받아 Chrome 또는 Edge로 엽니다.
- **문의:** 김진배 교수

## 버전

| 버전 | 용도 | 출력 |
|---|---|---|
| A | 일반과정 명찰 | A4 1장에 명찰 2개 |
| B | 이사장 과정 명패 (20 × 8.0cm, 앞뒤 양면) | A4 1장에 명패 1개, 칼질 2번 |

## 주요 기능

- 엑셀(.xlsx) 업로드
  - 컬럼 자동 매핑
  - 과정명은 시트 1행에서 가져옴
- 수기 입력: 엑셀에 없는 사람을 직접 추가
- 과정명 줄 수 선택: 자동 / 1줄 강제 / 2줄 강제 / 직접 입력
  - 직접 입력은 Enter 친 위치에서 줄을 바꾸고, 띄어쓰기도 그대로 출력
- 현재 적용 규칙 표시: 줄 수, 여백, 가로 폭 초과 여부
- 명패
  - 디자인 3종(A·B·C형), 디자인마다 따로 조정
  - 파란 재단선을 마우스로 끌어 위치 조정
- 관리자 모드(오른쪽 아래 🔒): 조정한 값을 기본값으로 넣은 새 HTML 파일을 저장해 배포

## 인쇄 설정

- 크기 100%, 여백 없음, 컬러 레이저 프린터
- 엑셀은 .xlsx만 지원합니다. 구버전 .xls는 엑셀에서 'Excel 통합 문서(*.xlsx)'로 다시 저장한 뒤 올려 주세요.

## 사용한 오픈소스

- pako 1.0.11 (MIT, Zlib): .xlsx 압축 해제용으로 파일 안에 포함
